# Приложение для учета долгов бизнеса

Простое и безопасное веб-приложение (SPA) для ведения учета задолженностей клиентов. Проект разработан с поддержкой многопользовательского режима (полная изоляция данных) и разворачивается в изолированном Docker-окружении под управлением Nginx.

##  Стек технологий

*   **Frontend:** React (Vite), Axios для HTTP-запросов, встроенный контекст авторизации.
*   **Backend:** Node.js, Express.js, JSON Web Tokens
*   **Database:** PostgreSQL
*   **Infrastructure:** Docker, Docker Compose, Nginx, Ansible, Yandex Cloud.

##  Функционал приложения

*    **Авторизация и Регистрация:** Хеширование паролей, защищенные JWT-токенами эндпоинты API.
*    **Полный CRUD долговых записей:** Создание, чтение, быстрое удаление и инлайн-редактирование любой записи.
*   **Система статусов:** Присвоение долгам статусов: *Активен*, *Погашен*, *Просрочен* с цветовой индикацией строк.
*   **Поиск и Фильтрация:** Мгновенный поиск по клиенту/комментарию и фильтрация по вкладкам статусов на стороне клиента.
*   **Калькулятор:** Автоматический расчет суммы активных и просроченных долгов в реальном времени.


## Архитектура Docker Compose (Продакшн)

В продакшн-окружении приложение запускается в виде трех изолированных контейнеров:
1.  `db_postgres`: База данных. Порты закрыты от внешнего мира. Данные сохраняются в именованный volume `pgdata`.
2.  `express_backend`: API-сервер. Порты закрыты. Доступен только для Nginx во внутренней сети Docker.
3.  `nginx_proxy`: Единственная публичная точка входа (порт `80`). Раздает скомпилированную статику React и перенаправляет запросы `/api/*` на бэкенд.

## Автоматический деплой (Яндекс Облако + Ansible)

Деплой полностью автоматизирован

### Шаг 1. Конфигурация Ansible на локальном ПК
Убедитесь, что в файле `inventory.ini` указан правильный IP-адрес вашей виртуальной машины в Яндекс Облаке, а также ssh ключ для доступа к ней:
```ini
[webservers]
your_vma_ip_here ansible_user=ubuntu ansible_ssh_private_key_file=~/.ssh/id_rsa
```

### Шаг 2. Запуск деплоя
Запустите команду автоматического обновления на вашем компьютере:
```bash
ansible-playbook -i inventory.ini deploy.yml
```

## Доступ после установки
При самом первом старте приложения скрипт автоматически создает одну учетную запись администратора для проверки системы:
*   **Логин:** `admin`
*   **Пароль:** `password123`

*После первого входа рекомендуется зайти во вкладку «Регистрация» и создать свой личный рабочий аккаунт.*
